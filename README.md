# SEAD-SA Income Dashboard

An interactive dashboard exploring provincial median income and income inequality in South Africa from 2014 to 2025.

## Dataset

The dashboard uses the Spatial Economic Activity Data: South Africa (SEAD-SA) province-level tax panel.

Source: [SEAD-SA data download page](https://spatialtaxdata.org.za/download-data-landing)

CSV files used:
- Province_MedianIncome.csv
- Province_Gini.csv


## Dashboard features

- Filter the data by province and tax year.
- View summary indicators for median income and the Gini coefficient.
- Explore three charts: income over time, income by province, and Gini coefficient by province.
- Responsive layout for desktop and mobile screens.
